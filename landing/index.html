FAQ

开始之前，你可能还想知道。

没有找到答案？可以在 GitHub 提交问题，或添加开发者微信 terlnai。

ChatGPT 助手是什么？+

ChatGPT 助手是由 Terln AI 打造的第三方 ChatGPT / Codex 桌面管理工具。它不是另一个聊天窗口，而是集中完成下载安装、环境配置、工作目录和 Skills 管理的统一入口。

必须有 API Key 才能使用吗？+

不需要。选择订阅模式后，客户端会处理模型接入所需配置，你无需自行准备 API Key。如果已有自己的模型服务，也可以主动切换到自定义模式。

需要手动配置特殊网络环境吗？+

订阅模式不要求用户手动配置额外网络或模型接口，安装后按照客户端引导操作即可。

支持哪些电脑？+

支持搭载 Apple 芯片且运行 macOS 14 或更高版本的 Mac，以及运行 Windows 10 1809 或更高版本的 Windows x64 电脑。后续不再支持 Intel 芯片 Mac。

订阅模式和自定义模式有什么区别？+

订阅模式适合希望直接使用的新用户，无需准备 API Key；自定义模式适合已经拥有模型服务的进阶用户，可以填写自己的 Base URL 与 API Key。

可以使用 Chrome 和 Computer Use 插件吗？+

可以在 ChatGPT 桌面端中按需启用 Chrome、Computer Use 等插件能力。首次使用时，需要按照系统提示完成插件安装和相应权限授权。

Plus、Pro、Max 的用量如何理解？+

Plus 约为官方 ChatGPT Plus 的月用量体验参考，Pro 约为 Plus 的 4 倍，Max 约为 Plus 的 10 倍。它不是固定消息数，实际消耗取决于模型、任务长度和工具调用情况。

这是 OpenAI 官方产品吗？+

不是。ChatGPT 助手是 Terln AI 独立开发的第三方桌面工具，用于帮助用户安装、配置和管理 ChatGPT / Codex 桌面工作流。

它适合作为 WorkBuddy 的替代选择吗？+

如果你更需要 ChatGPT / Codex 的本地工作流、工作目录管理、Skills 和插件扩展，ChatGPT 助手可以作为 WorkBuddy 等通用办公助手之外的专业选择。
